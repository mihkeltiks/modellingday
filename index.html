Step 1 — Discretise

Replace calculus with arithmetic

Running example from here on: heat spreading through a flat plate — the field is temperature T.

∂T/∂t = α∇²T

↓ finite differences on a grid of spacing h

T′[i,j] = T[i,j] + (αΔt/h²) ·
  (T[i+1,j]+T[i−1,j]+T[i,j+1]+T[i,j−1]−4T[i,j])

Five points per update: the cell and its four neighbours (the bracketed terms) — the five-point stencil. Stable only if αΔt/h² ≤ ¼.

The tool

MPI in sixty seconds

  • A supercomputer is many separate machines — no shared memory between them.
  • Message Passing Interface — the standard since 1994.
  • You launch P copies of one program. Each is a rank.
  • Memory is private. No shared variables.
  • Data moves only via explicit send and receive.
/* every rank runs this */
MPI_Init(&argc,&argv);
MPI_Comm_rank(COMM,&rank);
MPI_Comm_size(COMM,&size);

/* rank 0 sends first: avoids deadlock */
if (rank == 0) {
  MPI_Send(edge,n,MPI_DOUBLE,
           1,0,COMM);
  MPI_Recv(ghost,n,MPI_DOUBLE,
           1,0,COMM,&st);
} else {
  MPI_Recv(ghost,n,MPI_DOUBLE,
           0,0,COMM,&st);
  MPI_Send(edge,n,MPI_DOUBLE,
           0,0,COMM);
}

MPI_Finalize();

Halo exchange: the only conversation in the program

  • Only 2–4 messages per rank per step — interior ranks send four, boundary ranks fewer.

Does it scale?

Adding computers helps — up to a point

32² gridCells / computerExchangedOverhead
1 × 1102400 %
2 × 22563212.5 %

4 × 4642437.5 %

Smaller regions mean proportionally more edge. Past some point, each computer spends more time talking than computing.

  • More computers, same problem — regions shrink, edges don't. Gains flatten.
  • More computers, bigger problem — regions stay the same size. Keeps working.
  • Each message is tiny — at large counts you pay for the waiting, not the data.
Summary

Three things to take away

Grid decomposition

Cut the simulation region into parts, one per computer — parts only meet at their edges.

Adding computers helps

Speed up the same problem, or fit a bigger one across more computers.

Communication overhead

Sending messages takes time, and the share grows as computers are added — speedup is not always ideal.
